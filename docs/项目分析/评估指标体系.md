根据文档内容，多模态合规审核的评估指标定义如下：


### **1. 评估指标体系**
合规审核的评估指标分为**四个维度**，由不同的专业Agent负责：

| 审核维度 | 具体评估指标 | 评估方法 | 指标来源 |
|---------|-------------|---------|---------|
| **视觉审核** | NSFW（色情）、暴力、版权水印 | 视觉检测模型 + 特征匹配 | 业界标准 + 平台规则 |
| **音频审核** | 敏感词、违禁音乐 | ASR转写 + 敏感词库匹配 | 地区法规 + 平台政策 |
| **文本审核** | 字幕/台词违规内容 | LLM语义理解 + 规则引擎 | 多语言敏感词库 |
| **文化合规** | 地区规则适配性 | RAG检索 + 规则引擎 | 各国法规政策库 |


### **2. 评估流程与机制**
1. **并发检测**：四个维度的审核Agent并行执行，各自生成独立的风险报告
2. **信息汇总**：所有审核意见通过MsgHub广播给裁决Agent
3. **综合评分**：裁决Agent根据预设权重计算综合风险分数
4. **风险分级**：
   - 低风险 → 自动通过
   - 中风险 → 标注后人工复核
   - 高风险 → 直接打回


### **3. 指标定义主体**
- **政策来源**：各国法规（如GDPR、COPPA）、平台规则（如TikTok、Meta）
- **业务定制**：针对短剧特有场景（如古装打斗、言情场景）的评估标准
- **数据驱动**：基于历史审核数据和误判反馈持续优化


### **4. 技术实现**
- **视觉指标**：自训练ViT分类器，基于业务标注数据微调
- **音频指标**：Whisper ASR + 敏感词NER模型
- **文本指标**：LLM语义理解 + 多语言敏感词库
- **文化指标**：RAG检索政策文档 + 地区规则引擎


### **5. 评估结果输出**
- 结构化审核报告：`AuditResult(passed, risks, actions)`
- 详细风险点标注：具体违规内容和严重程度
- 处理建议：通过/打回/需人审的明确决策


### **总结**
合规审核的评估指标采用"**业界标准 + 地区政策 + 业务定制**"的混合模式，通过多维度并发检测和综合裁决，实现对短剧内容的全面合规评估。这种设计既保证了评估的专业性和准确性，又能适应不同市场的法规要求。
